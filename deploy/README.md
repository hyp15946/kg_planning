# 기획 볼륨 산출

기획서의 단계 목록에서 파트별 **개발 볼륨 / 디자인 볼륨**을 산출한다.
`[키글] 앱 종합 스케쥴` 의 볼륨 칸에 넣을 값이 최종 산출물이다.

## 쓰는 법

1. 사이트를 연다 → **`@kiglestudio.com` 계정으로 로그인**
2. 기준 데이터는 **드라이브에서 자동으로 불러온다** (따로 넣지 않는다)
3. **1. 기획서** — 프로젝트명 · 러프/상세 · 드라이브 링크
4. **2. 단계 목록** — 「드라이브에서 읽기」로 슬라이드에서 뽑거나 `steps.json` 을 불러온다
5. **2-1** 에서 단계 수를 먼저 확인하고 파트 키를 지정
6. **3~5** 등급 확정 · 디자인 가산 · 부대 항목
7. **6. 산출 결과** — 스케쥴 문서에 옮기고, 필요하면 JSON/CSV로 내보낸다

## 이 리포에 없는 것

**데이터는 리포에 넣지 않는다.** 리포가 공개이기 때문이다.

| 파일 | 어디에 있나 |
|---|---|
| `projects.json` | 드라이브 **`개발 볼륨 산출 데이터`** 폴더. 사이트가 이름으로 찾아 읽는다 |
| 기획서 링크 목록 | 위 파일 안에 들어 있다 |
| 추출한 단계 목록 | 각자 로컬 |

## 접근 통제

`@kiglestudio.com` 계정만 쓸 수 있다. **막는 것은 구글이고, 사이트가 아니다.**

| 층 | 실제 강제력 |
|---|---|
| OAuth Audience «내부» — 사외 계정 로그인 차단 | **있음** |
| 드라이브 파일 공유 권한 — 데이터 다운로드 차단 | **있음** |
| 사이트의 도메인 확인 — 화면 잠금 | 없음 (안내용) |

세 번째는 잘못된 계정으로 들어왔을 때 알려주기 위한 것이고, 코드를 고치면 통과된다.
**배포물에 데이터가 없으므로 통과해도 볼 것이 없다.** 지키는 일은 앞의 두 층이 한다.

데이터는 탭이 열려 있는 동안만 브라우저에 남고 탭을 닫으면 사라진다.
그래서 `projects.json` 을 덮어쓰면 모두가 다음 접속에 최신값을 본다.

## 구조

정적 HTML 한 개다. 빌드도 프레임워크도 없다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 전부 |
| `DEPLOY.md` | Vercel 배포 절차 |
| `OAUTH_SETUP.md` | 구글 설정 (로그인 · 드라이브 · 슬라이드) |
| `STEPS_SCHEMA.md` | `steps.json` 형식 |

세 군데로 격리되어 있어 방식을 바꿀 때 그 객체만 교체하면 된다.

| 객체 | 담당 |
|---|---|
| `GAuth` | 구글 OAuth (PKCE) · 로그인 계정 도메인 확인 |
| `Drive` | 드라이브에서 `projects.json` 찾기·받기 |
| `DataSource` | 기준 데이터 로딩 · 세션 보관 |

찾을 위치를 바꾸려면 `index.html` 상단의 `DATA_FOLDER` · `DATA_FILE` 을,
허용 도메인을 바꾸려면 `ALLOWED_DOMAIN` 을 고친다.

## 계산 방식

- **개발 볼륨 = 단계 단위 합산.** 게임 단위로 뭉개면 크게 과소 산정된다
- **디자인 볼륨 = 파트 단위 가산.** 등급표가 원래 파트 단위 가산 규칙이다
- **합산은 코드가 한다.** 단계별 등급과 근거를 함께 내보내 검산할 수 있다
- **소요일·개월은 계산하지 않는다.** 스케쥴 문서가 자동으로 계산한다

등급 후보가 둘 이상이면 하나를 고르지 않는다. 둘 다 띄우고 **기본값 없이 미정으로** 남기며,
미정인 단계는 합계에 들어가지 않는다.

## 배포

GitHub → Vercel. 브라우저만으로 된다. 빌드도 환경변수도 없다.
**절차는 `DEPLOY.md`**, 구글 설정은 `OAUTH_SETUP.md`.

놓치기 쉬운 것 세 개만 적어 둔다.

- Vercel의 **Root Directory 를 `deploy` 로** 지정한다 (HTML이 리포 루트가 아니다 — 안 하면 404)
- 배포 도메인을 OAuth 클라이언트의 **승인된 JavaScript 원본**과
  **승인된 리디렉션 URI**에 등록한다. 안 하면 사이트는 떠도 로그인이 안 된다
- **클라이언트 ID 는 리포에 넣지 않는다.** 시크릿은 아니지만 `localhost` 등록과 맞물리면
  드라이브 읽기 권한이 새는 경로가 생긴다 — `OAUTH_SETUP.md` 7번
